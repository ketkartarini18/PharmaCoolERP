# PharmaCool — Cold-Chain Warehouse & Logistics Management System

A full-stack cold-chain logistics platform built to manage pharmaceutical inventory, monitor temperature compliance, and track chain-of-custody across storage facilities and vehicles.

## Project Overview
* **Role-Based Portals:** Dedicated dashboards for warehouse personnel and delivery drivers with tailored KPI metrics.
* **Real-Time KPI Dashboards:** Interactive Chart.js analytics tracking storage capacity utilization, classification mix, and inbound/outbound volume trends.
* **Cold-Chain Excursion Tracking:** Automated detection, logging, and resolution monitoring for zone temperature excursions.
* **Chain-of-Custody Logging:** End-to-end traceability of lot transfers across vendors, warehouses, vehicles, and destination clinics.

## Architecture & Tech Stack
* **Backend:** PHP, MySQL (Relational Schema, Multi-Join Analytical Queries, Prepared Statements)
* **Frontend:** JavaScript (ES6, Chart.js), HTML5, CSS3
* **Environment:** Relational database integration with simulation-driven analytics
